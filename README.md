## 🌐 Overview

**OCTACORE** is an advanced 3D puzzle game running entirely in the browser. Powered by a custom Procedural Content Generator (PCG) with asynchronous Carving, it creates billions of unique 3D grids. The local AI learns from your strategies, requiring adaptive tactics to win.

**OCTACORE** è un puzzle game 3D avanzato eseguito interamente nel browser. Alimentato da un generatore procedurale (PCG) personalizzato con Scavo Asincrono, crea miliardi di griglie 3D uniche. L'IA locale apprende dalle tue strategie, costringendoti ad adattare le tue tattiche per vincere.

<br>

## ⚡ Features / Caratteristiche

- 🧠 **Adaptive Local AI:** L'Intelligenza artificiale memorizza i tuoi pattern vincenti utilizzando un database Hash Map in tempo reale. *(The AI memorizes your winning patterns using a real-time Hash Map database).*
- 🎲 **Procedural Generation (PCG):** Ogni livello è scavato algoritmicamente (Carving), garantendo geometrie sempre diverse e almeno 2 vie di vittoria possibili. *(Each level is algorithmically carved, ensuring ever-changing geometries).*
- 📱 **100% Offline PWA:** Installabile su Android, iOS e Desktop tramite Service Workers integrati. *(Installable on mobile and desktop via Service Workers).*
- 🎨 **Pure CSS 3D Engine:** Nessun motore grafico esterno o WebGL. Il 3D è calcolato interamente tramite regole geometriche CSS per una leggerezza assoluta. *(No WebGL. 3D is entirely calculated via CSS geometric rules).*
- 🌍 **I18n Multi-language:** Supporto nativo per 8 lingue, incluse scritture verticali tradizionali per Giapponese, Cinese e Mongolo. *(Native support for 8 languages, including vertical writing).*

<br>

## 🎮 How to Play / Come Giocare

1. **Rotate / Ruota:** Click and drag the background to rotate the 3D matrix. *(Trascina lo sfondo per ruotare la matrice).*
2. **Inject / Inietta:** Tap an empty green phosphor node to inject your `X` data. *(Tocca un nodo vuoto per iniettare il tuo dato `X`).*
3. **Hack the Core:** Align nodes (3 or 4 in a row depending on the sector size) in any 3D direction to bypass the firewall and defeat the AI. *(Allinea 3 o 4 nodi in qualsiasi direzione 3D per sconfiggere l'IA).*

<br>

## 🛠️ Installation / Installazione (PWA)

To install **OCTACORE** natively on your device:
1. Open the game link on your mobile browser (Chrome/Safari).
2. Tap the browser menu and select **"Add to Home Screen"** or **"Install App"**.
3. Play offline anytime!

Per installare **OCTACORE** nativamente sul tuo dispositivo:
1. Apri il link del gioco sul tuo browser mobile (Chrome/Safari).
2. Tocca il menu del browser e seleziona **"Aggiungi a schermata Home"** o **"Installa App"**.
3. Gioca offline quando vuoi!
